# Compliance and AI agents

Interactive companion pages for my LinkedIn series on compliance and AI agents.

- Series page: https://johntran777.github.io/compliance/
- Part 1, What non-compliance costs: https://johntran777.github.io/compliance/part-1/

## Put it online with GitHub Pages (about 5 minutes)

1. On GitHub, create a new **public** repository named `compliance`.
2. Choose "uploading an existing file". Drag in `index.html`, `README.md` and the whole `part-1` folder (dragging a folder keeps it as a folder). Commit.
3. Go to **Settings → Pages**. Under "Build and deployment", pick **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two, open https://johntran777.github.io/compliance/part-1/ and click through it, on your phone too.
5. Paste that address into LinkedIn's Post Inspector (linkedin.com/post-inspector) to check the preview card.

## Adding the next part

Make a `part-2` folder with its own `index.html` (and `og-image.png` for the preview card), upload it to the same repository, and change the Part 2 entry in the top-level `index.html` into a link.

If you rename the repository or use a custom domain, update the `og:` URLs at the top of each page so the preview images still load.
